# College Companion

An offline-first mobile application built with **React Native** and **Expo** designed specifically for students to effortlessly track academic attendance, store important college documents, manage course notes, and organize student expenses on the go.

---

## 🚀 Features

* **📅 Attendance Tracker:** Monitor class attendance percentages per subject, set low-attendance warnings, and log daily presence or absence.
* **📂 Academic Document Vault:** Securely store and organize your important student documents, ID cards, certificates, and fee receipts locally.
* **📝 Course Notes & Syllabus:** Keep track of lecture notes, study materials, and semester syllabi right on your device.
* **💰 Student Expense Manager:** Log daily expenditures, track category-wise student budgets, and keep your finances in check without needing an active internet connection.
* **⚡ Offline-First Architecture:** Built for reliability so your data stays accessible locally anytime, anywhere.

---

## 📱 Tech Stack

* **Framework:** React Native with Expo
* **Language:** TypeScript
* **Storage:** Local SQLite / AsyncStorage (Offline-first)
* **Styling:** Tailwind CSS (NativeWind)
